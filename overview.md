# API Overview

This API provides access to structured data through REST endpoints and returns responses in JSON format.

## Purpose
APIs like this are commonly used for:
- Testing and prototyping
- Learning REST integrations
- Building sample applications

## Base URL
https://swapi.py4e.com/api/

## Key Features
- REST-based architecture
- JSON responses
- Pagination support
- Linked resource navigation

## How It Works
- Client sends HTTP request
- Server processes request
- JSON response is returned

## Authentication
No authentication required

## Rate Limits
10,000 requests per day per IP
